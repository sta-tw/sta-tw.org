# 無學校信箱帳號申請的 Discord 審核

`/apply` 申請資料儲存後會立即寄出個人信箱收件確認信，不必等 Discord Forum 貼文建立完成。Forum 貼文會保留申請資料、附件連結與往返信件；申請者可直接回覆確認信補充資料。貼文下方的「通過／不通過」按鈕會完成審核。通過時系統依申請資料建立帳號並排入設定密碼／啟用信；寄信佇列保留同一封加密信件內容，啟用信最多自動重試 100 次。

帳號申請使用 `account@mail.sta-tw.org` 對應的信件路由與 Forum 頻道。請在管理後台確認 `account` 路由存在，且設定可審核人員的可見角色。API 的 Discord Bot token 需有建立 Forum 貼文及在討論串送出訊息的權限。

## 使用 `/re` 回覆或補正

Discord Application 的 Interactions Endpoint 使用既有信件系統網址：

```text
https://<STA_DOMAIN>/api/v1/internal/discord/interactions
```

工作人員在一般信件或帳號申請 Forum 討論串只需使用 `/re`，填寫回覆內容與簽名，確認預覽後寄送。系統會依討論串自動辨識一般信件或帳號申請；申請者直接回覆補正通知，回覆與附件會被收進原申請的同一串。

`/re` 與 Telegram 工作人員人工回覆都會寄給原寄件人，並密件副本到監督信箱；原寄件人是主要收件者，監督副本不會顯示給對方。帳號啟用、驗證與密碼重設等系統信不會抄送。
